# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun bounty "One-Line Roast: The Gadget You Use Every Day". The program writes a single original roast line to `/output/entry.txt`: our air fryer, which beeps like it invented fire and then serves fries burnt outside, frozen inside — and stays proud of both. The air fryer was picked because none of the 787 live submission titles mentioned it, while phones, earbuds, robot vacuums, microwaves, printers, and smartwatches were already crowded.

## Run

```sh
node main.ts
```

This writes the one-line roast to `/output/entry.txt` (109 characters, one line).
